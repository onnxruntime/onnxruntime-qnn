# QNN EP Coverage Artifact

This artifact contains the code coverage data for the ONNX Runtime QNN Execution Provider.

## Files

| File | Description |
|---|---|
| `coverage_lcov_filtered.info` | lcov data filtered to QNN EP sources only (`onnxruntime/core/providers/qnn/**`). Use this to regenerate the HTML report locally. |
| `diff-coverage.html` | Patch coverage HTML report generated by diff-cover. |
| `diff-coverage.txt` | Patch coverage text summary generated by diff-cover. |
| `README.md` | This file. |

## Regenerate HTML Report Locally

### Prerequisites

```bash
# Use the version managed by build_and_test.py (recommended)
python3 qcom/build_and_test.py create_venv
```

### Commands

```bash
# Download and extract the artifact, then run:
genhtml coverage_lcov_filtered.info \
    --output-directory coverage_html \
    --branch-coverage \
    --rc lcov_branch_coverage=1

# Open the report
xdg-open coverage_html/index.html
```

## Regenerate Diff Coverage Report Locally

```bash
# Prerequisites: activate the project venv
source venv/bin/activate   # or: python3 qcom/build_and_test.py create_venv

# Generate patch diff against main
git fetch origin main
git diff origin/main...HEAD > patch.diff

# Run diff-cover (output goes to same directory as coverage.xml by default)
bash qcom/scripts/linux/generate_diff_coverage.sh \
    --coverage-xml=coverage.xml \
    --diff-file=patch.diff

# View results
cat diff-coverage.txt
```
